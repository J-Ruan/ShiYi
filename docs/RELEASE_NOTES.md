# 拾忆 ShiYi 1.1.0

拾忆是一款完全离线的私人回忆收藏工具。本次升级统一了温暖、简洁的界面，并补齐记录入口、回收站与本地加密。

- 快速记录与继续添加；从相册、聊天应用的系统分享菜单导入一张或多张原图。
- 回收站保留 30 天，可恢复、撤销删除、永久删除；存储管理可预览安全清理文件。
- 精简全应用副标题和卡片文字，统一字体、间距与深色模式，高级选项按需展开。
- SQLCipher 数据库及 AES-256-GCM 原图加密，Android Keystore 保护随机密钥；历史数据先校验副本再清理旧文件。
- 备份兼容旧版 `.shiyi`，跨设备恢复保留本机安全设置；新增设置异常恢复页。
- 修复日历跨月选择和 CI SDK 初始化；PDF 加入目录、月份分隔页及完整页码。

最低 Android 8.0（API 26），包名保持 `com.shiyi.memory`。无账号、联网权限、云同步、广告、追踪、AI 或 OCR。

安装：下载正式签名 APK，核对 SHA256SUMS.txt 后允许系统安装该来源。旧 Debug 版与正式签名不同，不能覆盖安装：**先导出并验证加密备份，妥善另存，再卸载旧 Debug 版，安装正式版并恢复**。新手机不会复用旧设备的 Keystore 密钥。

限制：提醒受系统省电影响；受控分享 / PDF 导出会产生短期私有明文文件。生物识别能力依赖设备。具体已验证系统与尚未覆盖场景以当前 docs/TESTING.md 为准。本文件是发布模板，不能代替真实测试与发布状态。
