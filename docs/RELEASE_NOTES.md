拾忆 1.0.0 — 原生 Android 离线私人回忆收藏馆。

包括多图回忆、聊天收藏、TA 档案与双向关联、心愿、纪念日、日历、合集、中文搜索、统计、PDF、本地应用锁及完整加密备份恢复。

附件 `app-debug.apk` 使用 Gradle 默认 debug 签名，不是正式发行签名；Android 8.0+。应用不申请 INTERNET 或整个相册读取权限，关闭系统云备份。无 AI、OCR、广告或服务器。

请在导入私人内容前自行确认安装来源，并定期导出加密备份。应用锁控制访问，不代表内部数据库和媒体已加密。荣耀设备的省电策略可能延迟非精确本地通知。

实际测试范围和设备局限详见仓库 docs/TESTING.md；未执行的真机测试不视为已通过。
